Fix the offline limit for episodes, the update reload's timing and two notices

An episode's own contentRating is no longer stored under its show's key
in the poster cache: toPoster uses the show's rating when Plex sends it
and otherwise marks the rating as the episode's, which put() and
refreshRating() ignore, so a show never seen stays unrated and hidden
offline (fails closed, D37). A service-worker update now reloads only
at the daily reload's quiet moments (reloadMustWait). A first boot
provisioned from config.json writes the What's new marker, so a fresh
install sees no upgrade notice. The empty card blames the household
limit only when cached posters exist and none passes it (D73).
