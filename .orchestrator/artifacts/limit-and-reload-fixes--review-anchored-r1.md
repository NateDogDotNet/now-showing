## Issues

1. **Important · code-bug**, js/plex.js:135,144 — when Plex sends `grandparentContentRating`, the episode's own rating is dropped from `contentRating`, so the ONLINE now-playing limit (`permitted`, js/engine.js:71; `allowedOnScreen`, js/main.js:122) judges the playing episode by its series' rating. A TV-MA episode of a TV-PG series, and an unrated episode of a PG series, now pass a PG limit with "apply the limit to what's playing" on. In 2.1 as it was, both were refused.
   Evidence (probe `toPoster(ep,'now-playing')`, then `allows('PG', p.contentRating)`):
   ```
   head:  "TV-MA" (series TV-PG)   -> TV-PG  allowed under PG: true
   head:  no rating (series TV-PG) -> TV-PG  allowed under PG: true
   base:  "TV-MA" (series TV-PG)   -> TV-MA  allowed under PG: false
   base:  no rating (series TV-PG) -> ''     allowed under PG: false
   ```
   This breaks docs/spec.md:235: "a playing item above the limit (or unrated) is treated as nothing playing". The playing item is the episode. Criterion 2 asks that the descriptor "carries the show's rating" and leaves the mechanism to the builder. It does not ask that the show's rating replace the rating the live check reads. The handback says "the live limit check is unchanged", which holds only when the field is absent. No test pins the online behaviour when the field is present: tests/plex.test.js:449 asserts `contentRating === 'TV-MA'` (the series' rating) and so locks in the regression, and no e2e case uses the mock's new `grandparentRating` option. The display meta line (js/display.js:255) also shows the series' rating for an episode. That part is cosmetic. Severity: this is a content-limit breach and becomes Critical if real `/status/sessions` payloads carry `grandparentContentRating`. Nothing in the repo records whether they do (grep found the field only in the diff), so I rate it Important.
   Fix: keep `contentRating` as the episode's own rating for every episode. Put the series' rating in a separate field (e.g. `seriesRating`) that `put`/`refreshRating` store when it is present, and fall back to the existing `episodeRating` rule ("keep what is stored, else ''") when it is absent. Change plex.test.js:449 to assert both fields. Add a unit case: TV-MA episode, TV-PG series, PG limit, so the poster is not permitted and the cache stores TV-PG.
