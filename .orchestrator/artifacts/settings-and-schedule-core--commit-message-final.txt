Add the 2.1 settings keys and local-time schedule helpers

js/settings.js adds every new settings key with its default and sanitiser:
UI rotation, the status indicator, the poster cache limit, the content
rating limit, sleep and wake-on-playback, pixel shift, frame brightness,
night dim, the guarded daily reload, kiosk mode and the settings PIN, the
device helper, control labels, the metadata overlay and the landscape fill
mode. New numeric keys use a strict sanitiser: junk and blank values fall
back to the default, out-of-range numbers clamp and counts round. PIN
material is never exported and is ignored on import.

js/schedule.js holds pure local-time helpers: parseHHMM, inWindow (windows
may cross midnight; start equal to end is empty), msUntilNext (spring-forward
gaps resolve to the first valid instant, fall-back times fire once, never a
zero or negative delay) and isPlausibleClock (year at least 2026, for a Pi
without a real-time clock). sw.js precaches it.

Tests run the schedule cases under America/New_York and Europe/London.
