Add a guarded daily reload, drop the sheet blur, stop swipe-back

With dailyReload on (the default), the display reloads at
dailyReloadTime (04:00), and on the first wake from sleep that ends it
(schedule end or playback, not a manual wake) when the last reload is
over 12 h old. It never strands the display. It reloads only when a
service worker controls the page and a fetch('index.html', {cache:
'no-store'}) probe answers OK within 5 s; sw.js sends that one request
straight to the network. Otherwise it skips and logs why, and an http
LAN origin never reloads. It waits while a dialog is open, a poster
is loading or fading, the TV is waking or a manual wake is running. It
writes plexPoster.lastReload before reloading and refuses a second
reload within 10 minutes. An automatic reload keeps the idle-sleep
clock (carried in sessionStorage), and the page's load time follows a
clock jump at boot. Diagnostics shows Daily reload, Secure context
and Service worker rows, and Settings gains the reload controls.

The settings sheet loses its backdrop-filter blur (the panel is .98
opaque instead), and html and body get overscroll-behavior: none as
the in-page swipe-back backstop. The service-worker update timer no
longer throws when there is no registration.

tests/e2e/pi-stability.spec.mjs covers the reload rules, the guards
and the carried idle clock. tests/e2e/helper.spec.mjs gains the manual
and schedule-end wake cases with the device helper on.
