Rework Settings: connection card, minute presets, error fixes, first run

Settings opens on a "Connected to <server> · <library>" card. Change
reveals sign-in and the server picker, and library options show title
counts, loaded after the list (client.libraryCount reads totalSize)
so they never delay the connection test. The rotation time is picked
from 1/5/15/60-minute presets or a custom minutes value, still stored
as seconds (js/duration.js); the field shows exactly what will be
saved. Rare settings sit in a collapsed Advanced section.

Errors carry their fix. One table maps each error kind to actions
(sign in again, test connection, Diagnostics, turn off "unwatched
only"), used by the empty card, the toast (toast() takes a list of
actions) and the connection-test result. Fixes that change a setting
ask for the kiosk PIN, and the unwatched fix is offered only when that
setting is on.

An unconfigured display starts the plex.tv code flow by itself and
shows the code large and upright on the empty card, without opening
Settings. It checks for approval every 5 s, rests 5 minutes after
three codes expire unused, and stops while asleep. An approved
sign-in opens Settings pre-filled after the PIN; one approved during
a PIN prompt waits for it, with "Signed in. Open settings to finish."

Also: a Save that wakes the display rebuilds the Plex client first;
pixel shift and daily reload settings apply only on Save; the
household help text names its exceptions; the brightness slider shows
its value.

Tests: tests/duration.test.js, tests/plex.test.js,
tests/e2e/settings-sheet.spec.mjs and first-run.spec.mjs. The e2e
harness (tests/e2e/lib.mjs) stubs plex.tv by default and fails any
spec that reaches an outside host. The brightness and helper specs
pause their fake clock before timing checks.
