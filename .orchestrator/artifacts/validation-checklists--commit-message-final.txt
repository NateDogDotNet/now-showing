Add the real-server validation checklists

docs/validation/real-server-core.md lists the checks a person runs against a
real Plex server and plex.tv before the fix-first milestone closes: sign-in,
server discovery and the connection firstReachable picks, the token and URL
test, libraries, /status/sessions while playing and paused, the
/photo/:/transcode blob download without a CORS error, the offline fallback
and a 24 h soak.

docs/validation/real-server-extended.md lists every item the spec marks
(verify): the automatic first-run code, contentRating filtering and country
ratings, totalSize, viewOffset and Player.title, Chromium kiosk flags, the
Pi display-power and temperature commands, and token-rotation routes.

Every row has an ID, exact steps, an expected result that matches what the
app shows, Result: PENDING and Notes. Only Overall: PASS closes a validation
phase (D11). Neither file may hold a token.
